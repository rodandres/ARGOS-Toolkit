| Tipo       | Cuándo usarlo                                        | Ejemplo                                     |
| ---------- | ---------------------------------------------------- | ------------------------------------------- |
| `feat`     | Nueva funcionalidad                                  | `feat: add halo orbit generation`           |
| `fix`      | Corrección de un error                               | `fix: correct CR3BP state normalization`    |
| `docs`     | Solo documentación                                   | `docs: add API documentation`               |
| `refactor` | Cambio interno sin cambiar comportamiento            | `refactor: simplify fault injection flow`   |
| `test`     | Añadir/modificar tests                               | `test: add import validation`               |
| `chore`    | Mantenimiento que no es propiamente código funcional | `chore: configure development dependencies` |
| `perf`     | Mejora de rendimiento                                | `perf: reduce simulation memory usage`      |
| `style`    | Formato/estilo sin cambio de comportamiento          | `style: format controller modules`          |
| `build`    | Sistema de build/dependencias                        | `build: configure Python package`           |
| `ci`       | CI/CD                                                | `ci: add GitHub Actions workflow`           |
